Pool callers

Find contracts that called a pool during a transaction. View functions such as slot0 and getReserves emit nothing, so the scan reads execution traces rather than logs.

Leave the end block empty to scan this many blocks from the start, stopping at the chain head. Max blocks also caps a wide start–end range.

Functions

Each selector is the first 4 bytes of keccak256 of the canonical signature.

What a scan cannot see
  • Off-chain eth_call reads never land in a block. No RPC can list them.
  • The address in the table is the immediate caller, not the transaction sender. The sender is an extra column when the tx lookup succeeds.
  • Free trace endpoints are uneven. Some chains need your own RPC, and a quiet or pruned range can come back empty.
  • EOAs are dropped after eth_getCode, including EIP-7702 delegated accounts. A failed code lookup is kept and marked unknown.
